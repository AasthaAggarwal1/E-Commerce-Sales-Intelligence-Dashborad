# E-Commerce Customer Intelligence & Sales Analytics

An end-to-end data analytics project using **MySQL, SQL, Power BI, and DAX** to analyze e-commerce sales performance, customer behavior, product performance, retention, and customer segmentation.

The project transforms raw transactional data into business-focused insights through data cleaning, exploratory analysis, advanced SQL analytics, RFM segmentation, and an interactive two-page Power BI dashboard.

---

## 📌 Project Overview

This project analyzes the sales and customer data of an online retail business to answer important business questions such as:

- How is revenue changing over time?
- Which countries generate the most revenue?
- Which products contribute the highest revenue and quantity?
- Who are the highest-value customers?
- How many customers are retained or repeat customers?
- Which customers are at risk of being lost?
- Which customer segments contribute the most revenue?
- How frequently do customers purchase?
- What is the relationship between purchase frequency and customer revenue?
- Which products and customers are driving business growth?

The project follows an end-to-end analytics workflow:

**Raw Data → Data Cleaning → SQL Analysis → Customer Analytics → RFM Segmentation → Power BI Dashboard → Business Insights**

## 📂 Dataset

The project uses the **Online Retail II** transactional dataset.

### Dataset Details

- **Source:** UCI Machine Learning Repository
- **Business:** Online Retail
- **Geography:** Primarily United Kingdom with international customers
- **Time Period:** December 2009 – December 2011
- **Total Transactions:** 1,067,371
- **Countries:** 43
- **Identified Customers:** 5,943

### Main Columns

| Column | Description |
|---|---|
| `Invoice` | Invoice/order number |
| `StockCode` | Product identifier |
| `Description` | Product description |
| `Quantity` | Quantity purchased |
| `InvoiceDate` | Date and time of transaction |
| `Price` | Unit price |
| `CustomerID` | Customer identifier |
| `Country` | Customer country |
